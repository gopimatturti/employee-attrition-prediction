# 🏢 Employee Attrition Prediction

## 📌 Overview
A Machine Learning project to predict whether an employee will leave the company,
using HR data with 20,000 records and 29 features.

**Grade: 84% (A−) | AgileOlogy Data Science Capstone Project**

---

## 📂 Files in this Repository

| File | Description |
|------|-------------|
| `Employee_Attrition_Prediction.ipynb` | Main notebook — EDA + ML models |
| `capstone_employee_attrition_dataset.csv` | Dataset (20,000 rows, 29 columns) |
| `capstone_data_dictionary.csv` | Variable descriptions & data types |
| `Capstone_Problem_Statement_and_Data_Dictionary.docx` | Problem statement |

---

## 🔧 Tools & Technologies
- **Python** — Pandas, NumPy, Scikit-learn
- **Visualization** — Matplotlib, Seaborn
- **Models** — Logistic Regression, Random Forest

---

## 📊 Key Findings
- ~39.6% attrition rate in the dataset
- Overtime is strongly linked to employee attrition
- Marketing & HR departments show higher attrition
- Job satisfaction & work-life balance are key retention factors
